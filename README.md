Простой  веб-сервер для управления списком задач (автоматический перенос периодических задач, фильтрация, создание и удаление). 
Проект спроектирован  на Go с использованием стандартной библиотеки для роутинга и встроенной базы данных SQLite.

Требования для запуска
Установленный Go версии 1.21 или выше.
Браузер для проверки фронтенда.

Задания повышенной трудности не выполнялись

Клонируйте репозиторий и перейдите в корень проекта:
cd go-final

Загрузите необходимые зависимости: 
go mod tidy

(Опционально) настройте переменные окружения:
Вы можете переопределить порт или путь к базе данных:

# Для Linux/macOS
export TODO_PORT=7540
export TODO_DBFILE="scheduler.db"

# Для Windows (PowerShell)
$env:TODO_PORT="7540"
$env:TODO_DBFILE="scheduler.db"

Запустите веб-сервер:
go run main.go

База данных находится на адресе: 
http://localhost:7540/

В директории `tests` находятся тесты для проверки API
go test -run ^TestDB$ ./tests Тест проверки базы данных
go test -run ^TestNextDate$ ./tests Тест проверки вычисления следующуей даты для задачи в соответствии с указанным правилом
go test -run ^TestAddTask$ ./tests Тест для проверкидобавления задач
go test -run ^TestTasks$ ./tests Тест для проверки получения списка задач
go test -run ^TestEditTask$ ./tests Тест для проверки редактирования задач
go test -run ^TestDone$ ./tests Тест для проверки выполения задач
go test ./tests/... Запуск всех тестов

Директория `web` содержит файлы фронтенда.
